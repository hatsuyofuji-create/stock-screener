# 自由ペア分析 — 完成形（ファイル2つだけ）

フォルダ移動で壊れないよう、**必要なものを全部まとめた自己完結版**です。
この2つのファイルだけで動きます（`src/` や `universe/` フォルダは不要）:

```
app.py                    ← 全機能入り（計算・銘柄リスト・画面）
自由ペア分析アプリ起動.bat   ← ダブルクリックで起動
```

## 使い方（Windows）— ダブルクリックだけ

1. **Python** を入れておく（未導入なら https://www.python.org/downloads/ 。
   インストール時「Add python.exe to PATH」にチェック）。
2. `app.py` と `自由ペア分析アプリ起動.bat` を**同じフォルダに置いたまま**、
   **`自由ペア分析アプリ起動.bat` をダブルクリック**するだけ。

バッチが自動で次をやります（手作業のフォルダ整理は不要）:

- **短い場所へ自動コピー**: `%USERPROFILE%\pair-analysis`（例 `C:\Users\あなた\pair-analysis`）
  に app.py と自分自身をコピーし、そこから起動し直します（長いパス問題を自動回避）。
- **環境の自動修復**: `.venv` が無い/壊れている時は**自動で作り直し**、
  `streamlit / pandas / yfinance` を入れ直します（`.venv` を手で消す必要なし）。
- 準備ができるとブラウザでアプリが開きます。終了は黒い画面で **Ctrl+C**。

> つまり「フォルダを空にする」「ファイルをコピーし直す」といった手作業は不要です。
> どこから起動しても、常に短い場所で作り直して起動します。

## できること

- **ペア分析（1対1）**: 先行→後続を1ペア測る（β・つながりの太さ・急変時の追随率・散布図）。
- **連動ランキング（候補×みんな）**: 候補1銘柄と連動する銘柄を約250銘柄
  （日経225＋米国リーダー）から探して並べる。「先行→後続」重視で先行指標探し。
  - **連動率（同方向率%）** で順位づけ（ランダム50%・強いほど70〜95%）
  - **曜日ベスト**（例「月曜95%」）と **トレンド**（例「上昇中(前50→今90)」）も表示。
    “今効いているか”「特定曜日だけ強いか」が一目でわかる。

銘柄リストは画面の「探索ユニバース」欄で自由に追加・削除できます（1行 `コード 名前`）。
