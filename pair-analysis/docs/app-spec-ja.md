# 自由ペア分析 / 連動ランキング — 再構築のための仕様書

この文書は、Claude のプロジェクトに**ナレッジとして追加**し、
「この仕様書に従ってアプリを作って」と指示すれば**ゼロから同じアプリを再構築**できる
ことを目的にしています。末尾に**そのまま貼れる依頼文**があります。

---

## 0. これは何か（1行）

株式ペアの「**先行→後続（時間差の連動）**」を測る**検証・表示ツール**。
売買判断・自動発注はしない（あくまで候補を炙り出し、人が判断する）。

## 1. 3つの使い方

1. **ペア分析（1対1）**：先行1・後続1を指定して、その連動を詳しく測る。
2. **連動ランキング（候補×みんな）**：候補1銘柄に連動する銘柄を、多数（ユニバース）から探す。
3. **総当たりスキャン（バッチ）**：先行群×後続群を両方向で全部測り、連動率の高い順に出す。

---

## 2. 指標の定義（ここが本体）

前提：
- **日次リターン** `r_t = 終値_t / 終値_{t-1} − 1`
- **共通営業日で突き合わせ（align）**：2銘柄の日付の**積集合**で揃える
  （米国×日本など市場をまたぐカレンダー差を吸収）。
- **ラグ L**：後続を先行に対して L 営業日ずらす。米欧→日本は **L=1（翌営業日）**。
  同時間帯（日本/韓国/台湾）は当日(L=0)が「連れ高確認」、L=1が「遅れて張れる分」。

指標：
- **β（ベータ）**：後続リターン(t+L) を 先行リターン(t) に**最小二乗回帰した傾き**。
  「先行が1%動くと後続が平均どれだけ動くか」。しきい値に依らず全営業日で測る。
- **相関 r（Pearson）**：同じ組の相関係数。「**つながりの太さ**」表示に使う
  （|r|≥0.25=太い / ≥0.15=中 / それ未満=細い）。
- **連動率（同方向率）★主指標**：先行と後続の符号が一致した日の割合(%)。
  どちらかが 0（無変化）の日は分母から除外。**ランダムなら約50%、強く連れて動くほど70〜95%**。
- **急変イベント追随率**：先行が **±しきい値（3% / 5%）** を超えて急変した日だけ抽出し、
  翌 L 日に後続が**同方向**だった割合＋平均リターンを、**上げ / 下げ別**に出す。
- **曜日別連動率**：月〜金それぞれの連動率。「**月曜だけ95%**」のような偏りを発見。
- **期間別トレンド**：直近半分 vs それ以前の連動率を比較し、`上昇中 / 低下中` を判定。
  「**前50→今90**（上がってきた）」は使える、「昔90→今50」は使えない、という見立て。
- **リード/ラグ判定**：ラグを −3..+3 で走査し |相関| が最大のラグを採用。
  正=候補が先行、負=候補が後続、0=同時。

> 補足：**連動率は因果の保証ではない**。過去の統計であり将来を保証しない。

## 3. データ

- **プロバイダ抽象**：`get_close_history(symbol, period) -> (dates, closes)` の薄い契約。
  環境変数 `PRICE_PROVIDER` で切替（`synthetic` / `yahoo` / `jquants`）。
  UI・計算からデータ取得を分離する（yfinance 等を直書きしない）。
- **yahoo**：yfinance の調整後終値・日次。鍵不要。
- **jquants**：日本株全銘柄。V2・**APIキー方式**（`x-api-key` ヘッダ、`JQUANTS_API_KEY`）。
  「日付ごとに全銘柄バー」を取得して date×code 行列を作る（総当たりに好都合）。
  J-Quants の5桁コード → Yahoo 記法は「**先頭4桁 + .T**」。
- **synthetic**：シンボルから決めた乱数シードの擬似価格。鍵・ネット不要（テスト用）。

**シンボル記法（Yahoo）**：日本株4桁→自動で `.T`（6146→6146.T）、米株 `TSM`/`NVDA`、
指数 `^SOX`/`^N225`、韓国 `005930.KS`、台湾 `2330.TW`。

**期間ラベル**：半年(6mo)/1年(1y)/2年(2y)/3年(3y)/5年(5y)。

## 4. 画面（Streamlit・2タブ）

### タブ1：ペア分析（1対1）
- 入力：**先行 / 後続 / 期間 / 急変しきい値（±3% or ±5%）** ＋「分析」ボタン。
- 表示：
  - **ベータ**（先行1%→後続）
  - **つながりの太さ**（相関）
  - **↑急騰時 追随率**（回数中○%・平均±%）／**↓急落時 追随率**（同）
    ※回数<30なら「⚠回数少」
  - **株価の重ね描き**（共通開始=100 の折れ線）
  - **急変日の散布図**（x=先行%, y=後続%、色＝追随/逆行）

### タブ2：連動ランキング（候補×みんな）
- 入力：**候補銘柄 / 期間 / 並べ方（時間差 or 同日）/ 順位づけ（連動率 or 相関）/ 表示件数 /
  探索ユニバース（プリセット選択＋テキストで自由編集）/「先行している銘柄だけ」チェック** ＋ ボタン。
- プリセット：日経225＋米国リーダー（約250）/ 日経225のみ / 米国リーダーのみ。
- 表示：**連動率% / 曜日ベスト / トレンド / 関係（順=連れ高・逆=ヘッジ候補）/ 時間差 / 相関 / β** の表
  ＋ 連動率の棒グラフ。

## 5. 総当たりスキャン（バッチ `scan_all.py`）

- 先行群 × 後続群 を**両方向**で総当たり。各ペアで最良ラグ(0..max)の**連動率**を測り、
  **連動率の高い順**に CSV 出力。曜日ベスト・トレンドも付ける。
- 出力列：`先行 / 後続 / 連動率% / 先行日数 / 相関 / 曜日ベスト / トレンド / 直近% / 以前% / 日数`。
- 日本株全銘柄（約4000）は J-Quants で取得。**N×N は非常に重い**ので、
  まず「指数・米株（数十）× 日本株」から始める設計（既定）。

## 6. アーキテクチャ / ファイル構成

**配布形（推奨）＝自己完結1ファイル**：
```
app.py                    ← 全機能入り（計算・銘柄リスト内蔵・UI）。src/やuniverse/フォルダ不要
自由ペア分析アプリ起動.bat   ← Windows起動ランチャー
```

**開発用モジュール版**：
```
src/analysis.py     コア計算（リターン・回帰・相関・急変イベント）※純Python
src/coactivity.py   連動率・曜日別・期間トレンド                  ※純Python
src/rank.py         連動ランキング（候補×ユニバース）
src/universe.py     シンボル正規化・市場判定・既定ラグ・期間・ユニバース読込
src/data/           provider(抽象)+get_provider / yahoo / synthetic / jquants
analyze.py          1ペア分析CLI
find_peers.py       連動ランキングCLI
scan_all.py         総当たりスキャンCLI（CSV出力）
tests/              純Pythonの単体テスト（ネット不要）
```

**設計原則**：
- **コア計算は純Python（pandas/numpy 不要）**。UI・データ取得から独立させ、
  **ネット接続なしで単体テストできる**ようにする。
- データ取得は必ずプロバイダ経由（`PRICE_PROVIDER` で切替）。
- 配布は自己完結1ファイル＋バッチで、フォルダ移動で壊れないようにする。

---

## 7. Windows 起動バッチの要件（重要な落とし穴）

- **中身は ASCII のみ**（.bat に日本語を書くと CP932 環境で文字化けし、
  その行がコマンドとして誤実行されて壊れる）。メッセージは英語で書く。
- **パス長対策**：現フォルダのパスが短ければその場で実行、長すぎる（Windowsの約260字制限に近い）
  なら `%USERPROFILE%\pair-analysis` へ app.py と自身を自動コピーして起動し直す。
- **自己修復**：`.venv` が無い/壊れている（streamlit等が import できない）なら自動で作り直し、
  `streamlit pandas yfinance` を**名前指定で**インストール（requirements.txt に依存しない）。
- 実行時は `PRICE_PROVIDER=yahoo` を設定して `streamlit run app.py`。

## 8. 方針・注意

- **表示・検証専用**（売買判断・自動発注ロジックは作らない）。
- 秘密情報（APIキー等）はコード直書き禁止＝**環境変数**。
