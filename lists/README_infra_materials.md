# インフラ部材メーカー 銘柄リスト（`infra_materials_makers.csv`）

日本の上場企業のうち、インフラ（上下水道・道路橋梁・電力・ガス・鉄道・河川防災）向けの
部材・機材・資材を「製造販売」する銘柄を洗い出したもの。作成日 2026-09-19。

## 列の意味

| 列 | 内容 |
|---|---|
| 証券コード | 東証コード（前澤ホールディングスのみ英字入り `575A`） |
| 銘柄名 | 現社名。直近で社名変更した会社は旧社名を併記 |
| 市場区分 | プライム / スタンダード / 名証プレミア / 不明（検索で確認できなかったもの） |
| 東証33業種 | 東証の業種分類 |
| 分野 | 上下水道 / 道路・橋梁 / 電力 / ガス / 鉄道 / 河川・防災。複数該当は `\|` 区切り、先頭が主分野 |
| 主要インフラ製品 | インフラ向けの具体的な製品 |
| 区分 | 専業（インフラ部材の製造販売が主業） / 施工兼業（製造と工事の両方を持つ） / 多角化（インフラ向けは一部門） |
| 備考 | 判断根拠・注意点（親会社化、社名変更、製品の位置づけ など） |

| 確認状況 | 確認済＝Web検索結果（Yahoo!ファイナンス・かぶたん・松井証券・JPX等のタイトル）で証券コードと上場を裏取り済み。未確認＝周知の大型株を含め、今回の検索では裏取りしていないもの |

## 対象・除外の基準（指示書どおり）

- 対象：インフラ向け部品・資材・機器のメーカー（製造販売が主業）
- 除外：ゼネコン・サブコン・施工会社、商社、運営・コンサル・設計のみ、非上場、上場廃止済み
- 迷う場合（製造と施工の両方、多角化企業でインフラ向けが一部門）は除外せず「区分」列に明記して残した
- 総合鉄鋼・総合電機・総合重機・セメント大手は、インフラ向けに明確な製品群を持つものだけを「多角化」として参考収録した

## 調査手順

1. 6分野それぞれについて、使われる部材をカテゴリ分解（管・継手・バルブ・ポンプ・膜・薬品／鋼橋・支承・PC鋼材・防食・二次製品・防護柵・標識・照明・情報板／電線・碍子・鉄塔・電柱・金物・変圧器・開閉器・電力量計／ガス管・メーター・警報器・容器・LNGタンク／レール・分岐器・まくらぎ・トロリ線・信号・ホームドア／水門・排水ポンプ・護岸ブロック・鋼矢板・落石防護・ジオテキスタイル）。
2. 分野ごとに業界団体（日本ダクタイル鉄管協会、日本バルブ工業会、水道バルブ工業会、日本ポンプ工業会、全国ヒューム管協会、日本下水道施設業協会、日本橋梁建設協会、PC建設業協会、日本支承協会、全国コンクリート製品協会、日本電線工業会、日本電機工業会、日本鉄塔協会、日本ガスメーター工業会、信号工業協会、ダム・堰施設技術協会 など）の会員情報をWeb検索で確認し、プレーヤーを列挙。
3. 各社について、証券コード・上場市場・主要製品・直近の上場廃止/社名変更をWeb検索で確認。

### 調査上の制約

- 実行環境のネットワーク制限により、業界団体サイト・企業サイト・JPX・かぶたん等のページ本文は直接取得できず、**Web検索の結果（タイトル・要約）のみ**で確認している。
  そのため会員名簿の全社名は取得できておらず、名簿から拾えたのは検索要約に社名が出た範囲に限られる。
- 検索回数にも上限があり、大型株を中心に 31 銘柄は証券コードの裏取りを省略した（「未確認」）。
