# 短信収集アプリ 一式（受注高：PDF直読み版）

証券コードを入れるだけで、IRBANK経由で決算短信PDFを自動収集し、
売上高・受注高（各Q単独）・受注残高を抽出してCSVに出せるアプリの**一式**です。
受注高の抽出は、**PDFをそのままClaudeに渡す方式**にしてあり、表型・文字化けPDFにも強くなっています。

> 📌 **ファイル名を英語にしている理由**：Windowsのzip展開が日本語ファイル名を
> 文字化けさせることがあるため、フォルダ名・ファイル名は英語（ASCII）にしています。
> 中身（コメントやこの説明文）は日本語のままです。起動用バッチは `run_app.bat` です。

## 入っているファイル

| ファイル | 役割 |
|---|---|
| `tanshin_collector.py` | アプリ本体（Streamlit）。これを起動する |
| `ir_scraper.py` | PDF取得＋抽出（**PDF直読みパッチ適用済み**） |
| `ai_pdf_extract.py` | PDFをそのままClaudeに渡して受注高等を抽出（新方式の本体） |
| `ai_analyzer.py` | 従来のテキスト方式AI抽出（フォールバックとして使用） |
| `database.py` | 銘柄名の登録DB（**簡易版**。本物があれば差し替え可） |
| `run_app.bat` | ダブルクリックで起動するバッチ（旧「短信収集アプリ起動.bat」） |
| `requirements.txt` | 必要ライブラリ一覧 |
| `.streamlit/secrets.toml.example` | Claude APIキーの記入例（→ `secrets.toml` にコピーして使う） |

> ⚠️ `database.py` はこの一式を動かすための簡易版です。手元に**本物の `database.py`**（登録済み銘柄名入り）があれば、それに置き換えてください。空でもアプリは動きます。

## 使い方（初回セットアップ）

コマンド入力は不要。バッチをダブルクリックするだけです。

1. このフォルダを好きな場所に置く
2. **`setup.bat` をダブルクリック**（初回だけ。必要なライブラリを自動で入れる。数分）
   → 「完了しました」と出たらウィンドウを閉じる
3. AI抽出を使うなら、`.streamlit\secrets.toml.example` を同じ場所に
   **`secrets.toml`** という名前でコピーし、APIキーを記入
   （AIを使わない＝正規表現のみなら不要）
4. **`run_app.bat` をダブルクリック**
   （ブラウザが開かなければ http://localhost:8502 を開く）

> 次回以降は `run_app.bat` をダブルクリックするだけ（`setup.bat` は初回のみ）。

## 使い方（アプリ画面）

1. 証券コードを入力（例: 6125）→「🔍 決算短信を収集」
   → `決算短信PDF/{コード}/` にPDFが保存される
2. 「AIで抽出する」を**ON**にして「📊 保存済みPDFを解析」
   → 各Qの売上高・受注高（単独Q）・受注残高が表示される
3. 表を確認・編集して「📥 CSVをダウンロード」

「抽出元」列が **`ai_pdf`** になっていれば、新しいPDF直読み方式で読めています。

## 受注高が空欄・変な値のとき

- その銘柄のPDF（`決算短信PDF/{コード}/` の中）を確認してください。
- うまく取れないPDFがあれば、その1ファイルを共有してもらえれば抽出の指示（プロンプト）を調整できます。

## モデル・コストについて

- 抽出モデルは既定で `claude-opus-4-8`。環境変数 `ANTHROPIC_MODEL` で変更可
  （コスト優先なら `claude-sonnet-5` など）。
- AI抽出はAPI残高を消費します。「AIで抽出する」がOFFなら課金なし（正規表現のみ）。
