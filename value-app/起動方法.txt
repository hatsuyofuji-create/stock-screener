■ バリュー投資アプリ（上原メソッド）起動方法
--------------------------------------------------

【いちばん簡単な使い方（サンプルデータ）】
  1. 「バリュー投資アプリ起動.bat」をダブルクリック
  2. 黒いウィンドウが2つ開き、しばらくすると自動でブラウザが開きます
     （開かない場合は  http://localhost:5173  を手入力）
  3. 画面右上の「サンプル取込（mock）」ボタンで銘柄が入り、
     マトリクス・銘柄詳細・スクリーニング・予想Fスコアが試せます
  4. 終了するときは、開いた2つの黒いウィンドウを閉じてください

【実データ（J-Quants）を使う場合】
  1. 「実データ版で起動（J-Quants）.bat」をダブルクリック
  2. J-Quants の APIキー（ダッシュボードで発行）を入力
  3. 起動後、http://127.0.0.1:8000/docs から銘柄コードを指定して取り込み

--------------------------------------------------
【事前に必要なもの（最初の1回だけ）】
  ・Python 3.11 以上  … https://www.python.org/
      ※インストール時「Add Python to PATH」に必ずチェック
  ・Node.js（LTS版）  … https://nodejs.org/

  ※初回起動時に、必要な部品を自動でインストールします
    （数分かかります。2回目以降はすぐ起動します）

--------------------------------------------------
【うまくいかないとき】
  ・「Python が見つかりません」→ Python を入れ直し、PATH を通す
  ・「Node.js が見つかりません」→ Node.js（LTS）を入れる
  ・ブラウザが開かない → http://localhost:5173 を手入力
  ・免責：本アプリは投資助言ツールではありません。
          投資判断はご自身の責任で行ってください。
